DROP YOUR HERO BACKGROUND PHOTO HERE
====================================

Save ONE high-resolution photo into this folder and it will automatically
become the background image behind the headline on the home page.

- Accepted types: .jpg  .jpeg  .png  .webp
- Recommended: a wide / landscape shot, at least ~2000px across, so it stays
  sharp. A darker image (or one with empty space on the left) works best
  because white headline text sits on top of it.
- If more than one image is here, the first by filename is used.
- Delete this README once you've added your photo (optional).

Free, license-friendly photos you can download from your browser:
  https://unsplash.com/s/photos/luxury-modern-home
  https://unsplash.com/s/photos/modern-house-exterior
  https://unsplash.com/s/photos/modern-kitchen
(Right-click an image you like -> "Save image as" -> save it into this folder.)

If this folder is empty, the hero falls back to a clean dark design background
with the red accent — still sharp, just no photo.
